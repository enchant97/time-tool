# Time Tool
A simple CLI tool to get the time.

> Doesn't this already exist? Yes...

I just wanted a simple CLI program to output the current time in a specified format without hassle. I believe it accomplishes that; whilst having some extra features that are useful.

## Features
- Output the current date/time in specified location & layout
- Ticker mode, write time to STDOUT every second
- Output debug information from a NTPv4 query
- Supports NTPv4+NTS
- TUI mode
- Embedded documentation
